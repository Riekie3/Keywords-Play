# Keywords Play

A single-page keyword cloud builder. Type a center word, add keywords (comma-separated for several at once), and they spiral out around it.

- **Add / Undo / Shuffle / Clear** — build and rearrange the cloud
- **Tap a word** to remove it
- **Hide** — hides the controls for a clean view (for screenshots or presenting)
- **Save / Open** — named saved clouds (works when hosted as a claude.ai artifact; otherwise the current cloud is kept in the browser)

Open `index.html` in a browser — no build step.
